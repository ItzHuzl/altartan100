# Altartan 100

Монголын алдартнуудыг boost-оор эрэмбэлэх Next.js demo платформ.

## Онцлог

- Цэнхэр-ягаан gradient responsive UI
- Топ 3 медаль (алт, мөнгө, хүрэл)
- Boost систем (токен хасах + рейтинг өсгөх)
- Dashboard (токен ба гүйлгээний түүх)
- Админ панел (шинэ хүн нэмэх)
- NextAuth credentials authentication endpoint

## API

- `GET /api/people`
- `POST /api/people`
- `POST /api/boost`
- `GET /api/user`
- `POST /api/auth/[...nextauth]`

## Эхлүүлэх

```bash
npm install
npm run dev
```
